## Reporting a Vulnerability

If you discover a security vulnerability in the **SIH26025 (MINEGUARD)** system (including telemetry ingestion endpoints, authentication handlers, or Edge firmware interfaces), please report it responsibly:

1. **Do not create a public issue**: Do not disclose vulnerabilities in public GitHub issues or forum discussions.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email maintainer directly at `ronaldrex.ch@gmail.com`.
3. **Include Details**: Provide a description of the issue, affected endpoint or component, reproduction steps, and impact assessment.

Reports will be acknowledged within 48 hours and addressed promptly.
